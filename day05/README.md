# 📅 Jour 05 — Manipuler et analyser du texte

> [!IMPORTANT]
> Travaille dans l'ordre, teste chaque solution et crée plusieurs commits pendant la journée.

## 🎯 Objectif de la journée

Dans le monde réel, que ce soit pour le développement web, l'analyse de données, ou le "scraping" (extraction de données), vous passerez énormément de temps à manipuler du texte. Nettoyer des espaces en trop, vérifier qu'un email contient un "@", ou extraire le prix caché dans une longue phrase... Les **Chaînes de caractères (Strings)** ont leurs propres méthodes natives en JavaScript qui vous faciliteront la vie.

## ▶️ Démarrage rapide

Depuis la racine du dépôt, exécute un exercice avec :

```bash
node day05/exercices/exercice-01.js
```

Remplace `01` par le numéro souhaité. Pour contrôler toute ta progression :

```bash
npm test
```

## 🔁 Méthode de travail

1. **Lire** la mission et repérer les données fournies.
2. **Écrire** une première solution, même imparfaite.
3. **Exécuter** le fichier avec Node.js.
4. **Comparer** le résultat obtenu avec le résultat attendu.
5. **Corriger**, puis expliquer oralement la solution.
